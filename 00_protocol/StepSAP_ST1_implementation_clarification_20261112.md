## Safeguard on interpretation (author)
Organ displacement is an **anatomical measurement** (CT, frozen T_A). It is a patient-and-structure-level exposure; it does **not** establish that any specific FDG component was incorrectly matched, and it is distinct from registration error. ST1A/ST1B test **association, not causation** (SP7).

## ST1A (SP4)
- **A1:** Spearman ρ by MATLAB `corr(x, y, 'Type', 'Spearman')` (average ranks for ties). A bootstrap replicate in which ρ is undefined (a constant variable) is **invalid**, recorded and never assigned a value. The numbers of valid and invalid replicates are **always reported**. The 95 % CI (percentile) is reported only if ≥ 90 % of the 2,000 replicates are valid (implementation clarification, same pragmatic threshold as SP5); otherwise the point estimate is reported with the reason. An undefined point estimate is reported as such.
- **A2:** each correlation resamples only the patients evaluable for it (structure eligible for displacement in O1, or ≥ 1 eligible structure for the patient-level summary), with replacement; `rng(20261111, 'twister')` is **reset before each** of the 21 correlations (6 structures × 3 metrics + 3 patient-level summaries).
- Exposure: centroid distance, ASSD, HD95 from O1 (eligible records only). Outcome: primary DMTVF_ref. Patient-level summary per metric: median over the patient's eligible structures, reported with the number of contributing structures.

## ST1B (SP5)
- **A3, organ assignment:** reuse of the ST2a voxel-centre counts (native FDG PET voxel centres looked up in the FDG CT mask, nearest voxel; ST2 clarification D1). For a displacement-eligible structure, the ST2a mask contains all of its labels (verified by the ST2a O1 cross-check), so the count is the count in the structure's native FDG mask. Assigned if count / native voxel count **> 0.5** (exactly 0.5 is not assigned); the structure must be displacement-eligible for that patient; otherwise unassigned and not analysed. Units: eligible components classified V_M or V_U in the primary analysis; outcome V_U = 1, V_M = 0; exposure = ASSD (per mm) of the assigned structure.
- **A4, structure term:** categories in the fixed order spleen, kidney_right, kidney_left, liver, lung_left, lung_right; the reference is the first category present. The **locked category set** is the set present in the full-data fit. If only one category is present, the structure term has a single level and the model reduces to outcome ~ ASSD (reported).
- **A5, failed fit:** criterion (i) is applied by capturing the warnings issued by each `fitglm` call; a fit fails on any iteration-limit or separation warning (identifier or message); other warnings are recorded and reported, not used as failure. Criteria (ii)–(iv) exactly as SP5; criterion (iii) also fails a fit if the outcome has no variation.
- **Safeguard, bootstrap categories:** a bootstrap replicate whose category set differs from the locked category set (**category loss**) **cannot support the locked model and is counted as a failed replicate**; category losses are reported separately. No change of reference category, no removal of structures, no change of model or outcome.
- Bootstrap: patient-cluster (patients with ≥ 1 analysed component, with all their analysed components), 2,000 resamples, `rng(20261112, 'twister')`, percentile 95 % CI of the odds ratio per mm from the successful replicates. Fallback exactly as SP5: if the full-data fit fails, or > 10 % of the 2,000 replicates fail (any criterion, including category loss), the model is not reported. If the full-data fit fails, the bootstrap is not run.
- **A6:** the descriptive table (number of components and patients, median and IQR of ASSD by outcome and structure, and overall) is **always reported**, irrespective of model success.

## A7 Implementation and workflow
MATLAB script `ST1_association_v1_0.m` (R.8: all statistics in MATLAB); inputs MD5-checked (O1 table; primary P3 component and patient tables; ST2a components via its manifest; this note; SP spec). Self-tests: Spearman with ties against manual average ranks; undefined ρ flagged invalid and CI rule; assignment at exactly 50 % and displacement-ineligible structures; each failure criterion on synthetic data, including category loss; recovery of a known log-odds slope from simulated data. Workflow: self-test → full run → completion note. If the prespecified model fails, the descriptive fallback is accepted.
